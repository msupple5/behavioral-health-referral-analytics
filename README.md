# Behavioral Health Referral Operations System

## Project Premise

**Goal:** Design a fictional vertical SaaS workflow that helps a behavioral-health provider track referrals, contact prospective clients, schedule appointments, and measure access to services.

This project demonstrates how SQL, Power BI, and Salesforce can support referral management and operational decision-making for a behavioral-health provider.

## Project Status

This project is currently in development as part of my SQL, Microsoft Power BI, and Salesforce Administrator training.

## Business Problem

Behavioral-health providers need a reliable way to monitor prospective clients from the initial referral through first contact, appointment scheduling, and service enrollment.

Without a connected workflow, staff may struggle to identify:

* Referrals that have not received timely follow-up
* Delays between referral and first contact
* Delays between first contact and the first appointment
* Appointment no-show patterns
* Provider-capacity limitations
* Differences in access across counties or service types

## Intended Users

The fictional system is designed for:

* Intake coordinators
* Operations managers
* Program managers
* Provider-relations staff
* Clinical leadership

## Planned Workflow

1. A referral is received.
2. Intake staff record the prospective client's needs and location.
3. Staff attempt to contact the prospective client.
4. The referral is matched with an appropriate provider.
5. An initial appointment is scheduled.
6. Appointment attendance and referral outcomes are recorded.
7. Managers review operational performance through reports and dashboards.

## Planned Analysis

The project will examine:

* Total referral volume
* Referral-to-appointment conversion rate
* Average time to first contact
* Average time to first appointment
* Appointment no-show rate
* Active referral caseload
* Referral outcomes by county
* Provider capacity and utilization

## Planned Technology

* **SQL:** Querying, joining, filtering, grouping, and analyzing referral data
* **Power BI:** Data preparation, modeling, DAX measures, and interactive reports
* **Salesforce:** Referral workflow, custom objects, access controls, automation, reports, and dashboards
* **GitHub:** Project documentation and portfolio presentation

## Data and Privacy

All data used in this project is fictional and synthetically generated for educational and portfolio purposes.

This repository will not contain real patient, client, employee, provider, or employer information. The project is not a production healthcare system and should not be interpreted as demonstrating HIPAA compliance.
